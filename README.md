## ◈ About This Certification

The **freeCodeCamp Responsive Web Design Certification** is a 300-hour, fully project-based curriculum that teaches the core languages of the web. Every concept is learned by building — no passive video lectures, just hands-on code.

```yaml
certification : Responsive Web Design
platform      : freeCodeCamp.org
format        : Project-based (learn by building)
practice      : 15 guided projects
certification : 5 independent projects (test-suite validated)
total         : 20 projects completed
hours         : ~300 hours
skills        : HTML5 · CSS3 · Flexbox · Grid · Animations · Accessibility
```

## ◈ Core Concepts Mastered

### HTML5

```html
<!-- Semantic structure -->
<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>

<!-- Accessible forms -->
<form>
  <fieldset>
    <legend>Personal Info</legend>
    <label for="name">Name</label>
    <input type="text" id="name" name="name" required />
  </fieldset>
</form>

<!-- Responsive images -->
<figure>
  <img src="image.jpg" alt="Descriptive alt text" />
  <figcaption>Caption for the image</figcaption>
</figure>
```

### CSS Flexbox

```css
/* One-dimensional layout — row or column */
.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between; /* horizontal alignment */
  align-items: center;            /* vertical alignment */
  flex-wrap: wrap;                /* wrap on smaller screens */
  gap: 1rem;
}

.item {
  flex: 1 1 200px; /* grow · shrink · basis */
}
```

### CSS Grid

```css
/* Two-dimensional layout — rows AND columns */
.magazine {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  grid-template-areas:
    "header header header"
    "sidebar content content"
    "footer footer footer";
  gap: 1.5rem;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
```

### Responsive Design

```css
/* Mobile-first approach */
.container {
  width: 100%;
  padding: 1rem;
}

/* Tablet */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    display: grid;
    grid-template-columns: 1fr 3fr;
  }
}
```

### CSS Animations

```css
/* @keyframes animation */
@keyframes spin {
  0%   { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

.ferris-wheel {
  animation: spin 10s linear infinite;
}

/* Transition on hover */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}
```

### CSS Variables

```css
/* Define once, reuse everywhere */
:root {
  --primary:    #0A0A23;
  --accent:     #F59E0B;
  --text:       #1F2937;
  --bg:         #F9FAFB;
  --radius:     8px;
  --spacing-md: 1.5rem;
}

.button {
  background-color: var(--accent);
  border-radius: var(--radius);
  padding: var(--spacing-md);
  color: var(--primary);
}
```

### Accessibility (WCAG)

```html
<!-- ARIA roles and labels -->
<nav role="navigation" aria-label="Main navigation">
  <ul>
    <li><a href="#projects">Projects</a></li>
  </ul>
</nav>

<!-- Skip link for keyboard users -->
<a href="#main-content" class="skip-link">Skip to main content</a>

<!-- Descriptive alt text -->
<img src="chart.png" alt="Bar chart showing sales growth of 42% in Q3 2024" />

<!-- Visible focus styles -->
:focus {
  outline: 3px solid #F59E0B;
  outline-offset: 2px;
}
```
